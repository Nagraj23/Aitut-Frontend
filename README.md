## 🚀 Overview

AiTut is a role-based learning platform built using React Native and Expo that helps students identify skill gaps, generate personalized learning roadmaps, and learn through AI-powered tutoring experiences.

The platform also provides dedicated Training & Placement Officer (TPO) workflows for student management, progress tracking, and institutional monitoring.

---

## ✨ Features

### 👨‍🎓 Student Module

- 🔐 Authentication & OTP Verification
- 🧪 Diagnostic Skill Assessments
- 🗺️ Personalized Learning Roadmaps
- 🤖 AI Tutor Chat Assistant

- 💾 Persistent User Sessions

- Context-Aware AI Tutor
- Interactive Learning Conversations
- Personalized Responses
- Subject-Specific Guidance
- Markdown Content Rendering
- Text-to-Speech Support

### 🏫 TPO Module

- Branch Management
- Student Invitations
- Progress Tracking
- Branch Reports & Analytics

## 🚀 Getting Started

### Clone Repository

```bash
git clone <repo-url>
cd aitut
npm install
```

### Run Application

```bash
npm start
```

### Android

```bash
npm run android
```

### iOS

```bash
npm run ios
```
